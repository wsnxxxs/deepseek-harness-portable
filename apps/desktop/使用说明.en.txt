DeepSeek Harness for Win v1.7.4
================================

Chinese instructions: 使用说明.txt

Open DeepSeek Harness Launcher.exe to start the desktop app.
start-desktop.cmd provides console diagnostics; start-web.cmd opens the web UI.
Electron includes Node.js; no separate Node.js installation is required.

The default UI and presets come from official DeepSeek Harness 0.1.5-rc.2.
DCode, Learning, Cluster and desktop enhancements are disabled by default.
Management remains available in Settings → Web Plugins.
Enable the features you need and restart. Third-party marketplaces are no
longer seeded automatically; official page logos and menus are unchanged by default.

Add the relevant package to dsh.profile.bundles in DSH_HOME/profiles/web/package.json:
  @dsh-portable/interactive-learning
  @dsh-portable/dcode-ui
  @dsh-portable/cluster-ui
  @dsh-portable/desktop-enhancements
See docs/architecture-layers.md in the project for composition details.

Run dsh.cmd or update.ps1 to check published updates.
setup-shortcuts.ps1 creates shortcuts and adds the portable directory to PATH.
uninstall.cmd or uninstall.ps1 removes the app; follow its prompts about user data.
Keep runtime/ intact: it contains all application files.

Startup automatically migrates earlier Portable / Learning custom-event histories to official v3 logs. Original files remain unchanged; no history is deleted.

This build has no commercial CA signature. Windows may report an unknown publisher.
Verify downloaded files against the accompanying SHA256SUMS.txt.
